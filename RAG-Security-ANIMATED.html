Open Research Challenges07 / 14

Three Problems Nobody Solved Yet

PROBLEM 1
Obfuscated Instructions
Hidden prompts via invisible text, Unicode tricks, sentence-initials, indirect wording. Keyword filters miss them.
→ beyond regex
PROBLEM 2
Multilingual & Bangla
Almost all research is English-only. Low-resource languages like Bangla are unguarded attack surface.
→ we target it
PROBLEM 3
Verification Latency
Per-document LLM / cross-encoder checks cost >1.5s each — too slow for real-time QA.
→ lightweight instead
Our angle We target adversarial or inconsistent documents entering the index, including obfuscated instructions. The current experiment uses an outdated policy as a retrieval-contamination proxy, not a full PoisonedRAG attack.
